接口一览
方法 / 路径说明请求体
GET /api/health连通性探测，不需要登录—
POST /api/login登录，响应含 token{username, password}
GET /api/me当前登录状态 + 服务器信息—
POST /api/logout注销当前 token—
POST /api/password改网页密码{oldPassword, newPassword}
GET /api/players在线玩家，含是否装了 Cu—
GET /api/search?q=搜网易云，带可播状态—
POST /api/request点歌{id, name, artist, url, target}
GET /api/entries最近点歌与状态—
POST /api/message发消息进游戏聊天栏{target, text}
GET /api/chat游戏内对话镜像—
GET /api/netease/status网易云绑定状态—
POST /api/netease/qr申请扫码二维码（base64 PNG）—
GET /api/netease/qr/poll?key=轮询扫码状态—
POST /api/netease/login手机号密码登录网易云{phone, password}
POST /api/netease/cookie用 MUSIC_U 绑定{musicU}
POST /api/netease/logout解除绑定—

target 填玩家名，或 __all__ 表示全服；self / 留空表示自己。 出错时统一返回 {ok:false, error:"中文原因"}，HTTP 状态码同时给出语义（400/401/429/5xx）。
